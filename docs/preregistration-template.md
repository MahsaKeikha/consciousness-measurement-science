# Preregistration Template for Consciousness Measurement Studies

## Administrative record

- Study title:
- Protocol version/date:
- Investigators/sites:
- Ethics approval identifier:
- Data/code release plan:
- Registration location:

## 1. Experiential target

Choose exactly one primary target:

- presence;
- global state;
- content;
- phenomenal structure;
- capacity.

Define it operationally without using the candidate biomarker itself in the definition.

## 2. Allowed claim

State the strongest conclusion the study is designed to support and its intended M0-M7 claim level.

## 3. Forbidden interpretations

List conclusions the study cannot support even if the primary analysis is positive.

## 4. Population and contexts

- inclusion criteria;
- exclusion criteria;
- states/conditions;
- sites;
- expected missingness and uninterpretable recordings.

## 5. Evidence anchors

For each anchor (report, behavior, task EEG/fMRI, spontaneous neural data, perturbation, physiology), specify:

- measurement protocol;
- validation domain;
- known sensitivity/specificity or why these are unknown;
- known confounds;
- whether a negative result is interpretable as evidence against the target.

## 6. Primary prediction

Write the prediction in a form that can fail.

Example structure:

> Under conditions A and B, locked model M will improve held-out log score for target T by at least delta relative to baseline model B0, while preserving calibration within prespecified tolerance epsilon.

## 7. Rival explanations

List the major alternatives, including arousal, attention, memory, report preparation, movement, stimulus strength, pathology, medication, and site/hardware effects where relevant.

## 8. Positive and negative controls

Define controls before data access.

## 9. Preprocessing freeze

Specify:

- acquisition exclusions;
- artifact handling;
- filtering/referencing;
- feature definitions;
- time windows/regions/electrodes;
- missing-data rules;
- software versions.

## 10. Statistical model

Specify:

- hierarchical/repeated-measures structure;
- primary loss/statistic;
- uncertainty interval;
- multiplicity handling;
- priors where Bayesian;
- equivalence/noninferiority margins where relevant;
- abstention criterion;
- sensitivity analyses.

## 11. Data split

Declare discovery, internal confirmation, and external confirmation partitions. Participant/site leakage is prohibited.

## 12. Sample-size justification

Base the sample size on the primary endpoint, meaningful effect or interval width, repeated-measures design, site heterogeneity, missingness, and validation goal.

## 13. Falsification rule

State the observation that would count against the proposed measurement or theory claim.

## 14. Theory-specific predictions

If a theory is being tested, list the exact theory proposition, operationalization, divergent rival prediction, and auxiliary assumptions.

## 15. Structural-consciousness addendum

If phenomenal structure is tested, preregister:

- experience set;
- judgment task;
- reliability criterion;
- phenomenal distance/structure construction;
- physical representation;
- mapping family;
- held-out relation set;
- stimulus/semantic controls;
- distortion/alignment statistic;
- perturbation prediction if causal language is used.

## 16. Reporting commitment

Commit to publishing:

- all primary outcomes;
- null and failed theory predictions;
- calibration and uncertainty;
- exclusion counts;
- data-quality failures;
- deviations from preregistration;
- code and a machine-readable claim record where possible.
