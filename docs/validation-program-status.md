# Validation program status

The formal Research III validation program currently spans V1-V50.

- V1-V5: identification, finite-sample coverage, transport, dependence stress, and structural-alignment testing.
- V6-V10: finite calibration uncertainty, arbitrary missingness, inverse conditioning, heterogeneous-site partial identification, and resolution-based abstention.
- V11-V15: exact missingness-resolution laws, pooled multisite identifiability, sharp partial identification, resolution-driven sample-size design, and independent pilot-gated release.
- V16-V20: electromagnetic observables, gain invariance, matched-power non-identifiability, shared-field confounding, and frequency-specific organization.
- V21-V25: reference invariance, source non-identifiability, inverse regularization, multimodal complementarity, and forward-model perturbation.
- V26-V30: correlated-noise geometry, inverse resolution leakage, Fisher information, temporal aliasing, and singular-direction noise amplification.
- V31-V35: point-spread and cross-talk functions, covariance-aware source distinguishability, sensor-design information, nuisance information loss, and robust model uncertainty.
- V36-V40: finite-sample amplitude inference, inverse-covariance bias, Gaussian source discrimination, independent-search multiplicity, and covariance-mismatch calibration.
- V41-V45: arbitrary-dependence multiplicity control, Holm step-down testing, exact sign-flip inference, post-selection coverage, and independent confirmation.
- V46-V50: common-effect pooling, heterogeneity calibration, leave-one-site-out influence, partial-conjunction replicability, and site-weight concentration.
