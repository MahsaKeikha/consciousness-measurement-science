# Validation program status

The formal validation program currently spans V1-V10.

- V1-V5: merged analytic and synthetic validation layer.
- V6-V10: finite calibration uncertainty, arbitrary missingness, inverse conditioning, heterogeneous-site partial identification, and resolution-based abstention.
- Reader entry point: [`../VALIDATION.md`](../VALIDATION.md).
- Visual audit: [`validation-atlas.md`](validation-atlas.md).
- Machine-readable outputs: [`../results/`](../results/).

All stages remain measurement-science validation. Human empirical validation is a separate future milestone.
