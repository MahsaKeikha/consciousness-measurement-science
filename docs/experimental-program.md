# Experimental Program

## Phase 0 - Measurement specification

Before collecting data:

1. define target: presence/state/content/structure/capacity;
2. specify allowed claims;
3. list confounds;
4. preregister primary endpoint;
5. specify theory-specific and theory-neutral analyses separately;
6. define negative and positive controls;
7. freeze preprocessing for confirmatory evaluation.

## Phase 1 - Healthy benchmark

Within-subject repeated measurements across:

- normal wakefulness;
- controlled perceptual threshold/no-report tasks;
- NREM and REM sleep with awakening reports;
- graded sedation/anesthesia with multiple agents where ethically/clinically appropriate;
- dissociative conditions where responsiveness and experience may dissociate.

Acquire as feasible:

- high-density EEG;
- fMRI/MEG subsets;
- ocular signals;
- ECG/heart-rate variability;
- respiration;
- electrodermal activity;
- trial-level report and confidence;
- TMS-EEG in dedicated sessions.

## Phase 2 - Confound dissection

Manipulate independently:

- attention;
- working-memory load;
- motor response requirement;
- report delay;
- sensory strength;
- arousal;
- expectation.

A candidate measure should not be accepted if these variables reproduce its full effect without corresponding changes in experiential evidence.

## Phase 3 - Causal perturbation

Use perturbation to separate passive correlation from causal capacity.

Candidate tools:

- TMS-EEG;
- state-dependent stimulation;
- clinically justified pharmacology;
- focused ultrasound or intracranial stimulation only within established ethical/clinical protocols.

## Phase 4 - Disorders of consciousness

Multicenter protocol:

- serial CRS-R by trained examiners;
- standard EEG and sleep-pattern assessment;
- task EEG/fMRI for covert command following when feasible;
- resting quantitative EEG;
- TMS-EEG/PCI family where available;
- PET or resting-state fMRI in selected centers;
- repeated assessments to address fluctuation.

Primary outcome is not a binary “conscious/unconscious” label from one test. It is a multimodal evidence profile with calibrated uncertainty.

## Phase 5 - External validation

Lock models and evaluate at entirely held-out sites.

Report:

- sensitivity/specificity where a justified reference exists;
- calibration curves;
- likelihood ratios;
- abstention/inconclusive rate;
- subgroup performance;
- data-quality failure rates;
- transportability across hardware and sites.

## Phase 6 - Structural phenomenology

In communicative participants:

- collect high-reliability similarity/ordering judgments;
- estimate phenomenal geometry;
- estimate matched neural/causal geometry;
- preregister alignment metrics;
- test held-out experiences and participants;
- perturb neural geometry and predict phenomenal distortion.

## Phase 7 - Theory tournament

For each major theory:

- list unique predictions;
- specify pass/fail regions before data access;
- include independent analysts;
- publish nulls and theory failures;
- do not reinterpret every result post hoc as support.
