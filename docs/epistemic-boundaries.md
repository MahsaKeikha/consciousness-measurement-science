# Epistemic Boundaries

## Direct versus indirect access

A subject has first-person access to their own current experience. An external investigator has access to reports, behavior, physiology, neural recordings, and experimental interventions. This asymmetry is the defining measurement problem.

The project therefore distinguishes:

- **direct first-person evidence**: experience reports, similarity judgments, confidence, introspective structure;
- **third-person evidence**: observable signals and behavior;
- **bridge assumptions**: claims linking third-person variables to experience;
- **ontological claims**: claims about what consciousness fundamentally is.

No empirical marker can silently move from third-person evidence to ontological identity.

## The hard problem is not the measurement problem

Chalmers' hard problem asks why physical/functional processing is accompanied by subjective experience. The measurement problem asks what evidence justifies claims about presence, content, structure, or capacity for experience.

Progress on measurement can be real even if the hard problem remains open.

## Correlation, causation, identity

If neural variable \(X\) tracks report \(R\), three claims must remain distinct:

1. \(X\) predicts \(R\).
2. \(X\) causally contributes to the process producing experience/report.
3. \(X\) is identical to an experiential property.

(1) does not imply (2); (2) does not imply (3).

## Negative results

A negative result is interpretable only relative to assay sensitivity, data quality, and the participant's ability to engage the required process.

For task-based covert command following, a false negative can arise from language impairment, attention failure, fatigue, hearing loss, task comprehension, memory demand, motion, or analysis sensitivity even when experience is present.

## Theory neutrality

Theory neutrality is an aspiration implemented by:

- theory-independent benchmark tasks;
- explicit theory-specific analyses separated from generic measurement analyses;
- preregistered divergent predictions;
- blinded/held-out evaluation;
- adversarial collaboration when feasible;
- reporting results that challenge all theories.
