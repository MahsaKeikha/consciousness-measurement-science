# Examples

The files in this directory are synthetic, nonclinical examples that demonstrate how the repository's machine-readable research objects are intended to be used.

## `cep_example.json`

Illustrates a target-specific Consciousness Evidence Profile with mixed evidence and explicit clinical-use prohibition.

## `claim_example.json`

Illustrates an M6 structural-correspondence claim record with assumptions, falsification condition, and nonclaims.

These examples are documentation artifacts. They are not empirical results and must not be interpreted as participant data.
